常用的 DOM 操作

1️⃣ 选择 DOM 元素

getElementById()

通过 id 选择一个元素。

getElementsByClassName()

通过类名选择一组元素。

getElementsByTagName()

通过标签名选择一组元素。

querySelector()

通过 CSS 选择器选择第一个匹配的元素。

querySelectorAll()

通过 CSS 选择器选择所有匹配的元素。

2️⃣ 修改 DOM 元素内容

innerHTML

修改或获取元素的 HTML 内容。

innerText

修改或获取元素的文本内容（会忽略 HTML 标签）。

textContent

与 innerText 类似，但不考虑样式和 HTML 标签的影响。

3️⃣ 修改 DOM 元素属性

setAttribute()

设置元素的属性。

getAttribute()

获取元素的属性。

removeAttribute()

删除元素的属性。

classList.add(), classList.remove(), classList.toggle()

操作元素的类名。

style（内联样式）

设置或获取元素的内联样式。

4️⃣ 创建和插入新的 DOM 元素

createElement()

创建一个新的 HTML 元素。

appendChild()

将一个新元素添加到父元素的子元素列表末尾。

insertBefore()

将一个新元素插入到另一个元素之前。

insertAdjacentHTML()

将 HTML 插入到指定的位置。

5️⃣ 删除 DOM 元素

removeChild()

删除指定的子元素。

remove()

直接删除元素本身。

6️⃣ 事件操作

addEventListener()

为元素添加事件监听器。

removeEventListener()

移除事件监听器。

dispatchEvent()

触发一个自定义事件。

7️⃣ 滚动和视图相关操作

scrollTop

获取或设置元素的垂直滚动位置。

scrollIntoView()

使元素滚动到视口中可见的位置。

8️⃣ 获取元素尺寸与位置

getBoundingClientRect()

返回元素的大小和位置（相对于视口）。

clientWidth 和 clientHeight

获取元素的可视区域的宽度和高度（不包括滚动条）。

9️⃣ 文档相关操作

document.createElement()

创建一个新的 DOM 元素。

document.querySelector()

选择文档中第一个匹配的元素。

document.querySelectorAll()

选择文档中所有匹配的元素，返回一个 NodeList。

0️⃣ 动画与过渡

requestAnimationFrame()

调用一个函数来执行动画，通常用于创建平滑的动画效果。

总结

这些 DOM 操作可以帮助你动态地操作页面内容和结构，增加页面的交互性。常见操作包括选择元素、修改元素的属性或内容、添加或删除子元素、处理事件、获取元素位置、创建动画效果等。
